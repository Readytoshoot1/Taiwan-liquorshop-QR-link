# 위스키 정보 모음 (liquorshop_link)

위스키 관련 정보를 탭으로 나눠 보는 정적 웹페이지. GitHub Pages로 배포하며 휴대폰/PC 모두에서 볼 수 있다.
이 문서는 다른 대화창(새 세션)에서 작업을 이어받아도 막히지 않도록, 지금까지의 구조와 운영 방식을 전부 정리해 둔 것이다.

- 배포 주소: https://readytoshoot1.github.io/Taiwan-liquorshop-QR-link/
- 저장소: https://github.com/Readytoshoot1/Taiwan-liquorshop-QR-link (public)
- GitHub 계정: Readytoshoot1. 이 PC의 Git Credential Manager에 인증정보가 캐시되어 있어 `git push` 시 별도 토큰 입력이 필요 없다.
- 방문자 분석: GoatCounter (`index.html`에 스크립트 삽입) → https://abc12341.goatcounter.com 에서 확인

## 페이지 구성

상단 탭 5개로 나뉘어 있다.

1. **주류상점 QR** — 대만/일본 등 주류상점의 QR코드 이미지를 지역별로 모아 보여준다. 카드를 누르면 확대되고, QR 안의 링크(LINE, Instagram, 지도, 유튜브 리뷰 등)를 바로 열 수 있다. 가게 이름/지역 검색과 지역 탭 필터를 지원한다.
2. **여행 정보** — `travel_places.json`의 해외 호텔·음식점 장소를 보여준다. 분류 탭, 검색, 최신순/오래된순/이름순 정렬, "검토 필요만" 필터를 지원한다. (국내 정보와 관광지는 사용자 요청으로 제외했다.)
3. **유니온페이 할인** — 유니온페이 할인 정보 페이지를 탭 안에 iframe으로 불러온다. 페이지가 안 보이면 "새 창에서 열기" 버튼을 사용한다.
4. **세금 계산기** (`tax-calculator.js`) — 해외(USD/GBP/EUR/JPY)에서 위스키를 구매해 DHL로 대만·일본·한국에 보낼 때 드는 세금 + DHL 수수료를 계산한다. 위스키를 여러 병 담으면 국가별 세금·간이통관/정식통관 구분·통관 경고(5L/10L 한도 등)를 자동으로 보여준다. 환율은 `open.er-api.com`에서 자동으로 불러오고, 필요하면 직접 수정할 수 있다. 입력값은 `localStorage`에 저장된다.
5. **위스키 가격표** (`whisky/index.html` + `whisky/data.json`) — 대만 주류상점 22곳, 위스키 5,997병의 가격·WhiskyBase(WB) 점수 등을 조회하는 별도 서브 페이지를 iframe으로 띄운다. `data.json`이 8MB대로 커서 로딩이 느릴 수 있다. 이 탭의 생성 스크립트/파이프라인은 이 저장소에 없고(다른 작업에서 만들어진 결과물을 그대로 올린 것), 내부 구조를 깊이 알아야 하면 `whisky/index.html`을 직접 열어서 확인해야 한다. `Whisky_compact/whisky_compact_20261104.xlsx`는 아마 그 원본 엑셀로 보이는 로컬 파일이며, git에는 올리지 않았고 사이트에서 쓰지도 않는다.

## 매장 사진 갤러리

주류상점 카드와 확대 화면의 `매장사진(YYMM)` 버튼을 누르면 그 달에 찍은 사진 목록이 열리고, 한 장을 누르면 크게 보며 다시 누르면 원본 크기로 확대된다. `YYMM`은 촬영월(예: 2611 = 2026년 11월).
새 사진 반영 절차는 `CLAUDE.md`의 "정책 B"를 따른다 (`python build_shop_photos.py`).

- `Shop_photos/`: 원본 zip/폴더 (git 제외)
- `build_shop_photos.py`: 웹용 변환 + `photos.json` 생성
- `photos/<가게이름>/<YYMM>/`, `photos.json`: 변환 결과 (자동 생성)
- `photo_exclude.json`: 올리지 않을 사진 목록
- `gallery.js`: 갤러리 화면
- `CLAUDE.md`: 새 대화에서 따를 작업 정책

## 작업 요청 패턴 (중요)

이 프로젝트는 사용자가 "이미지/매장 추가했어 확인하고 업데이트해줘" 식으로 반복 요청하는 방식으로 운영된다. 매번 아래 순서를 따른다.

1. `git status --short`와 `images/` 폴더를 비교해 새로 추가/변경/삭제된 파일을 찾는다.
2. 새 이미지는 Read 도구로 직접 열어 QR코드인지 간판/명함 사진인지 확인한다.
3. QR이면 `python generate_manifest.py`로 자동 디코딩을 시도한다 (LINE/Instagram 등).
   - 한 이미지에 QR이 여러 개면 전부 추출된다 (`detectAndDecodeMulti` + CLAHE 보정 + pyzbar 보조).
   - **주의**: pyzbar는 특정 이미지에서 프로세스를 그대로 죽이는 크래시를 일으킨 적이 있다. 그래서 opencv로 먼저 시도하고, opencv가 하나라도 찾으면 pyzbar는 아예 호출하지 않는다.
4. QR이 없거나(간판/명함 사진) 추가 링크(구글맵, 유튜브 리뷰, 카카오톡, BAND 등)가 있으면 `link_overrides.json`에 수동으로 적는다. 여기 적은 값이 자동 디코딩보다 항상 우선한다.
5. 구글맵 단축링크(`maps.app.goo.gl/...`)는 `curl -A "Mozilla/5.0" <url>`로 302 응답만 확인하면 충분하다 (실제 리다이렉션 주소까지 열어볼 필요는 거의 없음).
6. 다시 `python generate_manifest.py` 실행 후, 디코딩 실패·링크 URL 중복(같은 LINE/지도 링크가 다른 매장명으로 중복 등록된 경우)을 파이썬 한 줄로 검사한다.
7. 중복이 의심되면 **먼저 사용자에게 확인**한다 (좌표나 매장명이 똑같아도 실제로는 다른 지점/다른 가게일 수 있음 — 과거에 "안적양주"와 "안적위양주"가 사실 같은 가게였던 적이 있고, "곱창국수"처럼 이름은 같아도 도시가 다른 별개 가게였던 적도 있었다).
8. 지역명이 이상하면 바로 고치지 말고 사용자에게 확인한다 (예: "주베이"를 오타로 오해해 틀렸던 적 있음 — 竹北/Zhubei라는 실제 대만 도시였다).
9. `git add` → `git commit` (한글 설명 + 아래 서명 포함) → `git push`.
10. push가 `remote: fatal error in commit_refs` 등으로 실패하면 GitHub 쪽 일시적 오류일 수 있으니 `git push`를 한 번 더 재시도한다.
11. 배포 반영은 `curl`로 `manifest.json`(또는 바뀐 파일)에 새 내용이 보일 때까지 백그라운드 polling 후 사용자에게 보고한다.

커밋 메시지 마지막의 `Co-Authored-By` 줄은 그 대화에서 Claude Code가 안내하는 최신 문구를 따른다.

## 주류상점 QR: 이미지 추가하는 법 (수동으로 할 경우)

1. `images/` 폴더에 `지역_가게이름.jpg` 형식으로 이미지를 넣는다.
   - 지역이 불명확하면 `불명_가게이름.jpg` 로 저장하고, 나중에 지역명만 바꿔도 된다.
2. (최초 1회) 필요 패키지를 설치한다.

   ```
   pip install opencv-python-headless pyzbar pillow numpy
   ```

3. 목록을 다시 생성한다. QR 안의 링크를 자동으로 읽어 `manifest.json`에 저장한다.

   ```
   python generate_manifest.py
   ```

   콘솔에 "디코딩 실패"가 나온 파일이 있으면 `link_overrides.json`에 직접 적는다. `note`는 생략 가능하다.

   ```json
   {
     "images/지역_가게이름.jpg": {
       "links": [
         {"label": "LINE", "url": "https://..."}
       ],
       "note": "예약 방법 등 추가 안내"
     }
   }
   ```

   - 여기 적은 값이 자동 디코딩보다 우선 적용된다.
   - 한 이미지에 QR이 여러 개인데 일부만 쓰고 싶으면(예: 송금용 QR 제외) 필요한 것만 적으면 된다.
   - `note`를 적으면 카드와 확대 화면에 안내 문구로 표시된다.
   - 같은 QR 링크가 파일명만 다르게 두 번 올라온 경우에는 기존 파일을 남기고 새 파일을 지운다 (사용자에게 먼저 확인).

4. GitHub에 반영한다.

   ```
   git add .
   git commit -m "이미지 추가"
   git push
   ```

5. 몇십 초 후 배포 주소에서 반영을 확인한다.

### 지역명 바꾸는 법

`images/` 안 파일명의 앞부분(지역명)을 바꾸고 `python generate_manifest.py`를 다시 실행한다. 지금까지 등장한 지역: 가오슝, 뉴타이베이, 신주시, 신베이, 주베이(竹北), 린커우, 타오위안, 타이베이, 타이중.

## 여행 정보: travel_places.json 편집하는 법

- 최상위 구조: `해외` 아래에 `호텔`, `음식점` 목록이 있고, `확인되지_않은_링크` 목록이 따로 있다.
- 항목 주요 필드
  - `name`: 장소 이름 (없으면 화면에 "장소명 미확인"으로 표시)
  - `subcategory`: 세부 분류 (예: 바, 파티룸)
  - `map_url`: 지도 링크 (Google Maps)
  - `chat_date`: 카카오톡 대화에서 공유된 날짜 (예: `2026.1.24`)
  - `shared_by`: 공유한 사람 (같은 곳을 여러 명이 공유했으면 콤마로 이어 적고, 날짜는 가장 오래된 것을 쓴다)
  - `needs_review`: `true`면 "검토 필요" 표시가 붙고 "검토 필요만" 필터에 걸린다
  - `note`: **비고 칸.** 필요한 정보를 자유롭게 적으면 카드에 표시된다.
- 확인되지_않은_링크: 장소명을 찾지 못했거나(구글 "저장 목록" 링크처럼 장소 특정이 안 되는 경우 포함) 접속이 안 되는 링크다. 화면에서는 "장소명 미확인"으로 보이며 항상 검토 필요로 취급한다.
- 구글맵 단축링크(`maps.app.goo.gl`)에서 장소명을 뽑아낼 때는 HEAD 요청의 `Location` 헤더(또는 리다이렉트 URL)에 들어있는 `/maps/place/<이름>,...` 혹은 `?q=<이름>` 부분을 그대로 쓴다. 네이버 지도 단축링크(`naver.me`)는 JS로만 렌더링돼서 이 방식으로 이름을 못 뽑는다 (시도하다 네이버 서버에 IP 레이트리밋 당한 적 있음 — 재시도하지 말 것. 네이버 쪽은 사용자가 별도로 요청할 때만, 요청 간격을 두고 조심스럽게 진행).
- 편집 후에는 JSON 형식이 깨지지 않게 주의하고, 이후 `git add`, `git commit`, `git push`로 반영한다.

## 세금 계산기 (tax-calculator.js)

- 구매 통화: USD/GBP/EUR/JPY 중 선택. 환율은 `open.er-api.com/v6/latest/USD` 기준(USD 대비 각 통화)으로 받아오고, 모든 환산은 이 표를 통해 교차 계산한다 (`tcCrossRate(from, to)`).
- 대만: 관세 0%, 담배·주류세(용량L×도수%×NT$2.5), 영업세 5%. CIF가 NT$50,000 넘으면 정식통관(G1), 총 용량 5L 넘으면 반입 불가 경고.
- 일본: 관세 0%, 주세(37도 기준 누진), 소비세 10%. CIF 20만 엔 넘으면 정식통관, 총 용량 10L 넘으면 경고.
- 한국(비교용): 관세 20% + 주세 72% + 교육세(주세의 30%) + 부가세 10%, 전부 종가세로 누적 계산. 주류는 금액과 무관하게 항상 정식통관으로 표시.
- DHL 수수료는 국가별 기본요금과 "대납 세금의 2%" 중 큰 값.
- 계산식은 사용자가 준 스펙(`tax_calculator.md`)을 그대로 구현한 것이며, 실제 세율·통관 기준은 수시로 바뀔 수 있으니 **법적 확정 자료가 아니라 참고용**이라는 점을 변경할 때도 유지할 것.

## 유니온페이 할인 정보

- 탭 안에 유니온페이 페이지를 iframe으로 표시한다.
- 해당 사이트가 외부 표시를 막는 경우 빈 화면이 보일 수 있다. 이때는 "새 창에서 열기" 버튼을 쓴다.
- 링크 주소는 `index.html`의 `#unionpay` 영역에 있다.

## 알아두면 좋은 점

- `manifest.json`은 `generate_manifest.py`가 덮어쓰므로 직접 고치지 않는다. 수동 링크는 `link_overrides.json`에 적는다.
- pyzbar는 특정 이미지에서 프로세스를 통째로 죽이는 문제가 있어서, 스크립트는 opencv로 먼저 찾고 실패한 경우에만 pyzbar를 쓴다.
- 흐릿한 QR은 대비 향상(CLAHE)과 단일/다중 디코더를 함께 써서 인식률을 높였다.
- 여행 정보·유니온페이·세금 계산기·위스키 가격표 탭의 실제 표시는 배포 후 휴대폰과 PC에서 한 번 확인하는 것이 좋다 (이 세션에서는 브라우저를 직접 열어 확인할 수 없어서, 코드/데이터 검증까지만 하고 사용자에게 눈으로 확인해 달라고 요청하는 식으로 진행해왔다).
